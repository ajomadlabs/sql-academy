Open the day you are on. It has one goal, the concepts behind it, and the problems that prove you have it. Forty-eight days, ordered so nothing depends on something you have not met.

Real Postgres, in the tab

Not a simulation and not SQLite. PostgreSQL compiled to WebAssembly, with a retail schema full of deliberate mess — nullable emails, unshipped orders, duplicate lines, gaps in the calendar. Window functions, recursive CTEs and EXPLAIN all work.

Answers are checked, not self-reported

Write a query, run it, and it is compared against the expected result. Aliases and column names are ignored, so a correct query written your way still passes. When it fails you are told how the result differed — never the answer.

Built for interviews, not trivia

Logical execution order, the NOT IN NULL trap, window frames, sargability, gaps-and-islands, slowly changing dimensions. The things that actually get asked, with the spoken answer written out for the ones you have to explain aloud.
